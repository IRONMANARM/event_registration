App me# Event Registration System

A lightweight Full-Stack Single Page Application (SPA) designed for capturing event attendee information. This project demonstrates a decoupled architecture with a responsive frontend and a persistent backend service.

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Client Logic:** JavaScript (ES6+)
- **Runtime Environment:** Node.js
- **Backend Framework:** Express.js
- **Database:** SQLite3
- **API Communication:** Fetch API (JSON)
